GitSentinel — Privacy Policy

Last updated: October 4, 2026

GitSentinel ("the extension") scans GitHub content you can already see for exposed secrets (API keys, tokens, credentials). All analysis happens locally in your browser. There are no accounts, no servers, no analytics and no tracking.

1. What Data We Collect

  • Scan findings — secret type, file, line and masked value. Raw secret values are never written to storage.
  • Your triage decisions — ignored items, accepted-risk baseline, tracked repositories.
  • Settings & scan cache — detection preferences, tree ETAGs, last scan state.
  • GitHub Personal Access Token (optional) — only if you provide one. Stored locally in plaintext and sent solely to api.github.com to authenticate your own API requests.

2. What We Never Do

  • Raw secret values are never written to storage, shown in notifications, or transmitted anywhere.
  • Saved data is never sold, shared with, or transmitted to any third party.

3. Third-Party Requests

The extension contacts only GitHub, and only content you already have access to:

  • github.com — reading visited repo pages for local scanning.
  • api.github.com — repository trees, PR diffs, job logs and release metadata. Authenticated only with your own optional PAT.
  • raw.githubusercontent.com — raw file contents for scanning (CDN, no API quota).

These requests are subject to GitHub's Privacy Policy. GitHub is a registered trademark of GitHub, Inc.; this extension is not affiliated with or endorsed by GitHub, Inc.

4. Data Retention and Deletion

Data stays on your device until you delete it: per-item ignore/baseline, per-repo data, full wipe from Settings, or uninstalling the extension (which removes everything).

5. Changes to This Policy

If this policy changes, the updated version will be posted at this URL with a new "Last updated" date.

6. Contact

For privacy questions, contact the developer through the Chrome Web Store listing page.
